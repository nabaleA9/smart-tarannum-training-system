Smart Tarannum Training System

This repository contains the implementation of a real-time Qur’anic tarannum
classification and scoring system using Mel-spectrogram features and a CRNN model.

Modules:
- Audio preprocessing
- Feature extraction
- CRNN-based classification
- Confidence-based scoring
- Streamlit GUI
- Arduino LED feedback interface

Note:
This repository is provided for academic transparency and demonstration purposes.
